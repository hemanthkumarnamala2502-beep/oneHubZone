# OneHub Zone - Citizen Services Portal

A comprehensive web application providing easy access to all government citizen services in one centralized location.

## Features

### 🏛️ Complete Service Categories
- **Identity & Documentation**: Birth certificates, passports, national ID cards, marriage/death certificates
- **Business & Licensing**: Business registration, trade licenses, industrial permits
- **Transportation**: Driver's licenses, vehicle registration, road tax payments
- **Property & Housing**: Property registration, building permits, housing schemes
- **Health & Welfare**: Health cards, vaccination certificates, welfare schemes
- **Education**: School admissions, educational certificates, scholarships
- **Utilities**: Electricity, water, gas, internet connections
- **Financial Services**: Bank services, tax services, loan applications
- **Legal Services**: Court services, legal documentation, legal aid

### 🚀 Key Features
- **Smart Search**: Find any service quickly with intelligent search functionality
- **Quick Actions**: Fast access to most common services
- **Emergency Services**: Direct access to emergency hotlines
- **Responsive Design**: Works perfectly on all devices
- **Interactive UI**: Modern, intuitive interface with smooth animations
- **Accessibility**: Built with accessibility standards in mind

### 🎨 Modern Design
- Clean, professional interface
- Intuitive navigation
- Mobile-responsive layout
- Beautiful animations and transitions
- Color-coded service categories
- Easy-to-read typography

## Technology Stack

1. Clone or download the project files
2. Open `index.html` in a web browser
3. No additional setup required - it's a static website

## Customization

### Colors
The application uses CSS custom properties for easy theming:
- `--primary-color`: Main brand color
- `--secondary-color`: Secondary elements
- `--accent-color`: Accent highlights
- `--text-primary`: Main text color
- `--background-light`: Light background

### Adding New Services
1. Add the service to the appropriate category in `index.html`
2. Update the search functionality in `script.js` if needed
3. Add any specific styling in `styles.css`

### Responsive Breakpoints
- Desktop: 1200px and above
